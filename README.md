# product-shopping
A responsive product shopping website built with HTML, CSS and JavaScript. It has login/signup, live products from an API, search, filter, sort and a shopping cart.

A simple and responsive online shopping website built using **HTML, CSS and JavaScript**.
Users can create an account, log in, browse products, add them to a cart and view their order total.

🔗 **Live Demo:** https://nalluriteja.github.io/product-shopping/

## ✨ Features

- 🔐 **Login and Signup** with password validation (minimum 6 characters, uppercase, lowercase, number and special character)
- 🚪 **Protected product page**: only logged-in users can shop, and there is a logout option
- 📦 **Live products** loaded from the [DummyJSON](https://dummyjson.com) API
- 🔍 **Search** products by name
- 🗂️ **Filter** by category
- ↕️ **Sort** by price, rating or name
- 🛒 **Shopping cart** with Add to Cart and Buy Now buttons
- 🔢 **Cart count** shown in the navbar
- 💰 **Order summary** with total items and total price
- 🧹 **Clear cart** option
- 💾 Cart and account data saved in the browser using `localStorage`

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- localStorage
- Font Awesome icons

## 🚀 How to Run

1. Download or clone this repository
2. Open `login.html` in your browser
3. Create an account, log in and start shopping!

## 📁 Project Structure

| File | Purpose |
|------|---------|
| `login.html`, `login.css`, `login.js` | Login and signup page |
| `index.html`, `style.css`, `script.js` | Product page |
| `cart.html`, `cart.css`, `cart.js` | Shopping cart page |

## 📌 Note

This is a learning project. Accounts are stored in the browser's `localStorage`, so each visitor creates their own account. A real website would need a backend server for secure login.
